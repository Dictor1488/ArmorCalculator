# unicorn.ares Armor Calculator

Легкий калькулятор пробиття броні для World of Tanks. Мод показує ефективну броню в точці прицілу та, за бажанням, додаткові параметри пострілу.

## Можливості

- приведена товщина броні, включно з екранами та рознесеною бронею;
- фактичне значення броні при рикошеті замість `-`;
- шанс пробиття;
- кут влучання;
- окреме значення пробиття;
- шанс добивання;
- індикатор перекриття гарматою;
- режим колірної сліпоти: червоний замінюється фіолетовим, жовтий і зелений не змінюються.

## Кольори

Кольори навмисно не винесені в налаштування:

- високий шанс — зелений;
- середній — жовтий;
- низький — червоний;
- рикошет — червоний;
- у режимі колірної сліпоти червоний стає фіолетовим.

## GameFace HUD

Відображення перенесене з GambitER/GUIFlash на GameFace.

HUD працює як один маленький пасивний `WindowLayer.VIEW` (шар 4), без fullscreen surface, без картинок, анімацій, таймерів та обробників миші. Весь DOM має `pointer-events: none`, тому калькулятор не призначений для взаємодії з курсором.

Контейнер автоматично змінює висоту залежно від кількості ввімкнених рядків. По горизонталі він центрується відносно екрана; базова позиція першого рядка — приблизно 35 px нижче центра прицілу. Масштаб інтерфейсу враховується через GameFace `viewEnv`.

Модель оновлюється тільки коли змінюється payload, тому статичні значення не надсилаються в GameFace повторно.

## Налаштування

У меню залишені тільки практичні параметри:

- увімкнення/вимкнення показників;
- режим колірної сліпоти;
- розмір шрифту;
- горизонтальне та вертикальне зміщення;
- поріг показу кута.

Формати тексту, кольори та параметри тіні захардкоджені.

Конфіг:

```text
mods/configs/unicorn.ares/armor-calculator.json
```

Старий конфіг `mods/configs/pademinune/armor-calculator.json`, якщо він існує, використовується лише для одноразової міграції налаштувань.

## Залежність

Для GameFace HUD потрібен **OpenWG.Gameface**. Власний layout мода реєструється через `res/mods/configs/res_map/armor_calculator_gameface.json` усередині `.wotmod`.

## Встановлення

Скопіюйте `.wotmod` до каталогу відповідної версії гри:

```text
World_of_Tanks/mods/номер_версії/
```

Після першої появи нового `res_map` OpenWG.Gameface може потребувати одноразового перезапуску клієнта для оновлення карти ресурсів.

## Принцип розрахунку

Мод використовує клієнтські дані World of Tanks про зіткнення снаряда з матеріалами броні. Ефективна броня накопичується через шари, а при рикошеті значення броні обчислюється перед завершенням перевірки, тому HUD може показати числове значення замість `-`.

Шанс пробиття оцінюється з урахуванням розкиду пробиття навколо середнього значення поточного снаряда.

## Відомі несумісності

Можливі конфлікти з іншими модами, які повністю замінюють ті самі приватні методи `_CrosshairShotResults` або змінюють логіку клієнтського маркера пробиття.
